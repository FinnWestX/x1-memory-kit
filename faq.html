Frequently asked questions.

Short answers about the FWX SimAviation helicopter mods, version 2.2.0. If something is missing, email us at support@fwx-simaviation.com.

Compatibility & requirements

Which simulator do the mods work with?

Microsoft Flight Simulator 2024 only, Microsoft Store and Steam edition. The installer finds both automatically. MSFS 2020 is not supported.

Which helicopters are supported?

Flight Dynamics works with every helicopter. Factory profiles tuned in flight exist for nine types (Cabri, R66, EC135, H125, H225, Bell 407, UH-1H, CH-47D, S-64F); other helicopters start from a general base profile. Tandem-rotor helicopters such as the Chinook are supported.

Rotor Shadow supports seven types: Airbus EC135, Airbus H125, Airbus H225, Guimbal Cabri G2, Robinson R66, Sikorsky S-64 Skycrane, Boeing CH-47D Chinook.

Rotor Haptic works with every helicopter.

The EC135 Turbine Sound works on the EC135 that comes with Microsoft Flight Simulator 2024. EC135 or H135 models from other developers are not supported, and every other aircraft sounds exactly as before.

What hardware do I need for Rotor Haptic?

A tactile transducer on its own audio output that Windows lists as an audio device. You choose this output in the Haptic tab of the FWX Control Center, so your headphones or speakers stay untouched. Without such a device Rotor Haptic has no effect.

The EC135 Turbine Sound works with any audio setup.

Does it work on Mac or Xbox?

No. Our mods require Windows. Xbox cannot install third-party Community add-ons, so they are PC-only.

Where do I set everything up?

In the FWX Control Center, the panel you open from the toolbar inside the simulator. Each product has its own tab. The help tab “?” contains a step-by-step guide with pictures and the full manual.

Installation & updates

How do I install?

Close the simulator and run the installer (.exe). There is one installer for all packages; it recognises which products your package contains and finds your Microsoft Store or Steam installation automatically. If the simulator is still running, the installer asks you to close it first.

Step by step: installation guide.

How do I update to version 2.2.0?

Download the current installer and run it; it replaces the installed files. Profiles saved with earlier versions can no longer be used and are removed during the update. All helicopters start with the new FWX factory profiles; press Save to create your own profile again.

How do I uninstall?

Close the simulator and remove the FWX entry in the Windows settings under installed apps.

Why does Windows warn about the installer?

The installer is not digitally signed. Click More info and then Run anyway.

My download stalls at the end and never finishes. What can I do?

With large files, some browsers do not finish the download properly even though the file has already been fully transferred. The progress bar then sits at the end without any error message.

Have a look in your downloads folder: the file is usually there with an extra extension such as .part or .crdownload. Remove that extra extension so the file name ends in .exe again. You can then run it as normal.

If that does not help, download the file into a different folder, for example straight to C:\Temp. On a work computer, try once over your private network.
