What it does

The default EC135 sounds are flat and without character. This mod replaces them completely, inside and out, with recordings of real helicopters.

It is made for one single helicopter and works only there: the Nemeth Design EC135, the one that comes free with the simulator as Local Legend 21. No other EC135 and no other helicopter is changed by it.

In every other aircraft the mod simply rests. Nothing is switched on, nothing has to be switched off, and the simulator sounds exactly as it did before.

What you hear in the cockpit

  • Every phase of flight. Cold start, spool-up, idle, flight, shutdown - each with its own character.
  • A start you can abort. You can stop the spool-up at any point, just like the real aircraft.
  • Two engines, treated separately. Uneven start, uneven shutdown, taxiing on one engine.
  • Straight from the starter into the turbine run. No gaps, no cuts, no audible seam.
  • Smooth under load. Torque changes come through as a smooth shift, not as an abrupt jump in pitch.
  • Safe for bass shakers. No unwanted rumble in the cockpit audio, so the low end stays where you put it.

From the outside

  • The twin-turbine howl that gives this helicopter its signature from a distance.
  • Downwash, flyby and hover completely reworked.
  • Every outside view has its own sound, so the machine changes as you walk around it.

What it does not do

  • It works on the EC135 only. Every other helicopter stays untouched.
  • It changes nothing about the flight behaviour and nothing about the visuals.
  • It creates no vibration. That is what the FWX Helicopter Rotor Blade Haptic is for.

Compatibility

  • Microsoft Flight Simulator 2024. PC, Steam or Microsoft Store. MSFS 2020 is not supported.
  • Windows 11. Not available on Xbox, which cannot install third-party add-ons.
  • The Nemeth Design EC135, included free with the simulator as Local Legend 21. Nothing else to buy.
  • No effect on frame rate.
  • Runs next to the FWX Helicopter Rotor Blade Haptic without getting in its way.

Using the panel

You set everything inside the simulator. The FWX Control Center is a panel in the simulator itself: you open it from the toolbar in mid-flight, set what you want, and close it again. There is no window outside the simulator you have to operate or keep running - nothing to alt-tab to just to change a setting.

The panel has one page per FWX add-on - Flight Realism, Rotor Shadow, Haptic, Sound Pack - plus a News page with our current notes. The master switch sits at the top, everything belonging to that page below it. Every change takes effect at once, without a restart.

There is nothing to set for the sound itself - it is there the moment you load the EC135. The Sound Pack page exists for the one thing that depends on your PC:

  • The output device. You pick from a list which output the FWX sounds run through - headphones, speakers or a particular sound card. Apply & Save, and it still applies next time.
  • Plain words instead of guesswork. Short lines tell you whether the add-on is connected, whether it is in the right helicopter, and which device it plays on. Sit in another type and it says exactly that - and the simulator sounds the way it always did.
No extra program to operate
The device choice lives in the panel inside the simulator too. There is no Windows application you have to open or keep running for it.

Installing it

  1. Run the installer. One file, nothing to unpack, nothing to copy by hand. Choose Install when it opens.
  2. Confirm the folder. It finds the right folder for the Microsoft Store and the Steam edition on its own. A custom location can be pointed to by hand.
  3. One setting inside the simulator. The order in which the simulator loads its packages has to be set once, so the new sound is the one you hear. The installer walks you through it with a confirmation dialog.
  4. Start the simulator and load the EC135. Start the engines - the new turbine is there.
Reversible at any time
Run the same installer again and choose Uninstall. It removes itself cleanly, and the default EC135 sounds come back exactly as they were.
