Installation guide.

Setup for all FWX SimAviation helicopter mods, version 2.2.0. One installer handles every package. Once installed, everything is set in the FWX Control Center panel inside the simulator.

Requirements Packages Install FWX Control Center Update Troubleshooting Uninstall

Requirements

  • ✓ Microsoft Flight Simulator 2024 on a Windows PC, Microsoft Store or Steam edition. The installer finds both automatically.
  • ✓ For the EC135 Turbine Sound: the EC135 that comes with Microsoft Flight Simulator 2024.
  • ✓ For Rotor Haptic: a tactile transducer on its own audio output that Windows lists as an audio device.
  • ✓ For the download: bought on our website, the email address of your purchase and your order number. Bought on SimMarket, your SimMarket account.

Flight Dynamics and Rotor Haptic work on every helicopter. Rotor Shadow supports seven types: Airbus EC135, Airbus H125, Airbus H225, Guimbal Cabri G2, Robinson R66, Sikorsky S-64 Skycrane, Boeing CH-47D Chinook. The EC135 Turbine Sound works on the EC135 only.

Install

  1. Download the installer. Bought on our website: open the download portal and enter the email address of your purchase and your order number. You can download up to 3 times per purchase, and the portal always delivers the current version. Bought on SimMarket: download it from your SimMarket account.
  2. Close the simulator. Exit Microsoft Flight Simulator 2024 completely. The installer checks this before it starts and asks you to close the simulator first.
  3. Run the installer (.exe). There is one installer for all packages. It recognises which products your package contains. Windows SmartScreen may show a warning because the installer is not digitally signed. Click More info and then Run anyway.
  4. Follow the steps on screen. The installer finds your Microsoft Store or Steam installation of Microsoft Flight Simulator 2024 automatically. If a file cannot be written, it shows “Installation INCOMPLETE” together with the affected files.
  5. Start the simulator and open the FWX Control Center. Open the panel from the toolbar in the simulator. Each product has its own tab.

Setting up in the FWX Control Center

  • • Help tab “?”: a step-by-step guide with pictures and the full manual. Packages with Flight Dynamics also include the manual as a PDF in English and German.
  • • Flight Dynamics: works with every helicopter. Factory profiles tuned in flight for nine types (Cabri, R66, EC135, H125, H225, Bell 407, UH-1H, CH-47D, S-64F); other helicopters start from a general base profile. Adjust the settings and press Save to create your own profile; the factory profile always stays untouched. With an airplane loaded, the FWX tabs are greyed out, because Flight Dynamics works with helicopters only.
  • • Rotor Shadow: can be switched on and off per helicopter type.
  • • Rotor Haptic: choose your transducer as the output device in the Haptic tab and set the strength there. The tab also shows the number of rotor blades of the current helicopter.
  • • EC135 Turbine Sound: choose your headphones or speakers by name in the Sound tab.

Update to 2.2.0

Download the current installer the same way as above and run it. It replaces the installed files.

Important: profiles saved with earlier versions can no longer be used and are removed during the update. All helicopters start with the new FWX factory profiles. Press Save to create your own profile again.

Troubleshooting

The installer asks me to close the simulator.

Exit Microsoft Flight Simulator 2024 completely and run the installer again.

The installer shows “Installation INCOMPLETE”.

Some files could not be written; the installer lists them. Make sure the simulator is closed and run the installer again. If the message stays, send the list to support@fwx-simaviation.com.

SmartScreen warns about the installer.

The installer is not digitally signed, so Windows may warn. Click More info and then Run anyway.

The Haptic tab shows no device.

Windows does not list your transducer as an audio output yet. Check the Windows sound settings, then close and reopen the FWX Control Center. The device then appears in the list.

The FWX tabs are greyed out.

An airplane is loaded. Flight Dynamics works with helicopters only; load a helicopter.

Where is my download?

Bought on our website: use the download portal with the email address of your purchase and your order number. Bought on SimMarket: your SimMarket account. If it does not work, email support@fwx-simaviation.com with your order number.

Uninstall

Close the simulator. Then remove the FWX entry in the Windows settings under installed apps.

Still stuck?

Email support@fwx-simaviation.com. We will help you.
